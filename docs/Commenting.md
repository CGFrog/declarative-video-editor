<h1>Commenting Your Code</h1>
<p>Like most programming languages, DVEL supports comments inside of code. Currently, DVEL only supports single-line comments.</p>

<h3>Comment Syntax</h3>

```
% This is a comment
```
<p>Use the percentage ( % ) symbol to denote the start of a comment.</p>

```
game_footage after intro 1 % The game footage plays after the intro
```
<p>DVEL also allows comments on the same line as previous code. Again, these comments are still denoted by the percentage ( % ) symbol.</p>
